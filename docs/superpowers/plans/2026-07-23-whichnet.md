# whichnet Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `whichnet` crate: a `current_identity()` function that returns the strongest available network-identity signal (Wi-Fi SSID, falling back to default-gateway MAC) on Linux and macOS.

**Architecture:** A platform-agnostic `IdentitySource` trait and fallback-ordering logic in `src/lib.rs`, unit-tested with mocks. Real sources live in `src/linux.rs` (nl80211 netlink), `src/macos.rs` (CoreWLAN), and `src/fallback.rs` (netdev gateway MAC), each gated by `#[cfg(target_os = ...)]`.

**Tech Stack:** Rust 2024 edition. Dependencies: `nl80211 = "0.0.2"` (Linux only), `objc2-core-wlan` (macOS only — pinned to whatever version `cargo add` resolves on the macOS build machine in Task 4, since it cannot be resolved from this Linux dev environment), `netdev = "0.45"` with `gateway` feature (both platforms).

## Global Constraints

- Edition: 2024 (already set in `Cargo.toml`).
- Crate name: `whichnet` (already set in `Cargo.toml`).
- No shell-outs to external CLI tools (`iwgetid`, `nmcli`, `networksetup`, `system_profiler`) — native APIs only, per spec.
- No macOS TCC-bypass workarounds (IORegistry keys, root-owned plist reads) — per spec, out of scope.
- Windows unsupported in this plan — per spec, out of scope.
- Platform-specific source code (Linux nl80211, macOS CoreWLAN) is not unit-testable on an arbitrary CI runner without the real OS/hardware; only the fallback-ordering logic in `src/lib.rs` gets deterministic unit tests, per spec's Testing section.

pub(crate) fn resolve_identity(source: &dyn IdentitySource) -> NetworkIdentity {
    if let Some(ssid) = source.ssid() {

pub(crate) struct NetdevFallback;

impl NetdevFallback {
    pub(crate) fn gateway_mac(&self) -> Option<([u8; 6], Option<std::net::IpAddr>)> {
        let gateway = netdev::get_default_gateway().ok()?;
        let mac = gateway.mac_addr.octets();
        let subnet = gateway
            .ipv4
            .first()
            .map(|ip| std::net::IpAddr::V4(*ip))
            .or_else(|| gateway.ipv6.first().map(|ip| std::net::IpAddr::V6(*ip)));
        Some((mac, subnet))
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn gateway_mac_returns_a_value_or_none_without_panicking() {
        // This is an environment-dependent integration check, not a
        // deterministic assert (CI runners vary in network setup).
        // It only verifies the call doesn't panic and the shape is sane.
        let result = NetdevFallback.gateway_mac();
        if let Some((mac, _subnet)) = result {
            assert_eq!(mac.len(), 6);
        }
    }
}

pub(crate) struct Nl80211Source;

impl Nl80211Source {
    pub(crate) fn ssid(&self) -> Option<String> {
        let mut socket = nl80211::Socket::connect().ok()?;
        let interfaces = socket.get_interfaces_info().ok()?;
        interfaces
            .into_iter()
            .find_map(|iface| iface.ssid)
            .and_then(|bytes| String::from_utf8(bytes).ok())
    }
}

#[cfg(test)]
mod tests {
